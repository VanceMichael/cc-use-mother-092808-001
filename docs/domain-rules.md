# 领域边界

管理宏观预测调查样本、规则版本、发布水位和事后误差。

现有领域资料围绕以下边界组织：

- 调查样本与匿名贡献
- 修订水位
- 共识规则
- 发布冻结
- 误差回测

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 后端不变量

`src/forecast_backend/` 实现以下不可违反的领域规则：

1. **修订水位单调**：已发布版本的快照（`computed_json` / `sample_json`）一旦写入永不修改；迟到修订只能进入更高版本号的新发布。
2. **撤回不抹除历史**：撤回只改变当前生效状态，历史发布快照中"当时参与共识"的事实保留，误差仍按当时数值计算。
3. **四眼原则**：规则与发布稿的批准者必须不同于定义者；同一作用域同一时刻只有一条生效规则。
4. **匿名下限**：任何对外聚合（实时共识、发布稿）要求有效机构数 ≥ 规则下限（默认 3，最低 2）；统计视角的身份一律替换为按轮次生成的匿名代号，跨轮次不可串联。
5. **回执幂等**：回执编号唯一；同编号同内容返回首次结果，同编号不同内容进入隔离区且不产生任何提交。
6. **误差可追溯**：实际值登记后，共识误差与机构误差按发布版本分别落盘；超阈值偏离生成下一轮复核标记，关闭需留说明。
7. **重启可续**：提醒、待审批规则与发布稿全部持久化；`recover()` 幂等，同一提醒只触发一次。
